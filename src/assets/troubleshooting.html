Troubleshooting

Installing Chrome for Testing Manually (Windows)

Some users may have trouble downloading the Chrome browser required by Puppeteer, particularly in countries or on networks where Google's download servers cannot be reached. These steps download Chrome independently of Puppeteer and npm.

Use the exact Chrome version required by your Hajonsoft release. The example below is version 131.0.6778.87. Do not replace it with the latest Chrome version unless it is the version required by your release.

Step 1: Open Command Prompt

  1. Go to the Windows Desktop.
  2. Press Windows + R.
  3. Type cmd and press Enter.

Step 2: Navigate to the Desktop

Enter this command and press Enter:

cd /d "%USERPROFILE%\Desktop"

Step 3: Download Chrome for Testing

Download the exact Chrome version required by this Hajonsoft release:

curl -L -o chrome-win64.zip https://storage.googleapis.com/chrome-for-testing-public/131.0.6778.87/win64/chrome-win64.zip

Wait for the download to finish before continuing.

Step 4: Extract the downloaded ZIP file

Run this command to extract the archive into a folder on your Desktop:

powershell -Command "Expand-Archive -Path '.\chrome-win64.zip' -DestinationPath '.\chrome-win64' -Force"

Step 5: Verify the Chrome executable

Check that the extracted Chrome executable exists:

dir ".\chrome-win64\chrome-win64\chrome.exe"

The expected executable location is:

%USERPROFILE%\Desktop\chrome-win64\chrome-win64\chrome.exe

Step 6: Verify the Chrome version

Run Chrome with the version option:

".\chrome-win64\chrome-win64\chrome.exe" --version

Expected output:

Google Chrome 131.0.6778.87
After extraction, provide the executable path to Hajonsoft/Puppeteer if automatic browser detection does not find it. Keep the path and version matched to the current Hajonsoft release.
